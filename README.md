# UI/UX Designer Portfolio Template

> A mobile-first, accessible personal portfolio website built with clean BEM-structured CSS, an elegant camel-inspired warm color palette, and semantic HTML5 markup.

---

## Features

- **Accessibility-First Engineering**:
  - Skip-to-content navigation link (`.skip-link`) for keyboard and screen reader accessibility.
  - ARIA landmark roles, semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`), and dynamic `aria-expanded` attributes.
- **Warm Aesthetic & Design Tokens**:
  - Earthy, warm camel-inspired color scheme with refined neutrals, high-contrast text ratios, and subtle surface elevations.
  - Dual typography system integrating Google Fonts [Poppins](https://fonts.google.com/specimen/Poppins) for headings and [Inter](https://fonts.google.com/specimen/Inter) for reading text.
- **Strict BEM CSS Architecture**:
  - Predictable, maintainable Block-Element-Modifier class naming throughout `styles.css`.
  - Zero bloated CSS frameworks—100% pure vanilla CSS with custom variables and responsive container utilities.
- **Comprehensive Portfolio Sections**:
  - **Hero Header**: Headline, subtitle, call-to-action buttons, key statistics, and a designer preview card.
  - **About Me (`#about`)**: Personal background, design philosophy, and career objectives.
  - **Skills Matrix (`#skills`)**: Structured breakdown of technical proficiencies and design tools.
  - **Selected Projects (`#projects`)**: Multi-column project showcase grid with tags, summaries, and action links.
  - **Services & Experience (`#experience`)**: Service offerings and career milestone timeline.
  - **Contact Section (`#contact`)**: Client inquiry contact form and social media links.
- **Mobile Responsive**: Fully responsive layout adapting effortlessly from small smartphones to large desktop displays.

---

## Tech Stack

- **Markup**: HTML5 (Accessible, semantic, W3C-compliant structure)
- **Styling**: CSS3 (Pure Vanilla CSS, BEM naming methodology, CSS Variables, Flexbox, CSS Grid)
- **Typography**: Google Fonts ([Poppins](https://fonts.google.com/specimen/Poppins) & [Inter](https://fonts.google.com/specimen/Inter))

## How to Install and Run

No build tools or compilers are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jatin2267/check.git
   cd check
   ```

2. **Open in browser:**
   - Double-click `index.html` to open in any web browser.
   - Or run a local development server:
     ```bash
     npx serve .
     ```
   - Open `http://localhost:3000` in your web browser.
